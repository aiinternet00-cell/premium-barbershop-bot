# Демонстрационный Telegram-бот премиального барбершопа

Учебный проект на Python и aiogram: клиент выбирает услугу, одного из шести мастеров, дату и свободный час, а администратор получает уведомление. **Все названия, цены, контакты, адрес и отзывы демонстрационные.**

## Возможности
- запись только на ближайшие 14 дней без прошедших дат;
- часы: пн–пт 10:00–21:00, сб–вс 11:00–20:00; шаг записи 60 минут;
- независимое расписание мастеров и повторная проверка слота при подтверждении;
- «Моя запись»: ближайшая запись, услуга, цена, мастер, дата, время и отмена с подтверждением;
- уведомления администратору о создании и отмене;
- адрес, контакты, карта, отзывы и защищённая `/admin`-панель;
- SQLite, автоматическое создание таблиц и заполнение услугами и шестью мастерами;
- `/help` и `/cancel`, валидация ввода, логирование и понятные ошибки конфликтов.

## Быстрый запуск для новичка

### 1. Создать бота
1. Откройте Telegram и официальный аккаунт **@BotFather**.
2. Отправьте `/newbot`, задайте имя и username, оканчивающийся на `bot`.
3. BotFather пришлёт токен вида `123456:ABC...`. Никому его не показывайте.
4. Свой числовой Telegram ID узнайте у **@userinfobot** (или другого ID-бота) — он станет `ADMIN_ID`.

### 2. Установить Python и проект
Установите Python 3.11+ с [python.org](https://www.python.org/downloads/) (в Windows отметьте **Add Python to PATH**). Затем в терминале:

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. Настроить `.env`
Скопируйте `.env.example` в `.env` и замените значения:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_ID=ваш_числовой_id
DATABASE_PATH=barbershop.db
```

`.env` уже исключён из Git. Никогда не публикуйте токен, не вставляйте его в код или скриншоты. При утечке выполните `/revoke` в BotFather.

### 4. Запустить и остановить
```bash
python bot.py
```
Откройте бота, нажмите Start или отправьте `/start`. Для остановки нажмите **Ctrl+C** в терминале.

## Как проверить запись
1. Нажмите «Записаться», выберите услугу, мастера, дату и время.
2. Введите имя и телефон, подтвердите. Аккаунт с `ADMIN_ID` получит полные данные клиента.
3. Попробуйте то же время у того же мастера: оно исчезнет. У другого мастера оно останется.
4. В «Моя запись» отмените запись и подтвердите отмену: слот снова появится, администратор получит сообщение.
5. Отправьте `/admin` с аккаунта администратора. Другим пользователям доступ запрещён.

## Бесплатный хостинг
Подойдёт сервис с Python worker и постоянным диском, например бесплатный тариф Render/Railway, если он доступен. Создайте Git-репозиторий **без `.env`**, подключите его к сервису, задайте build-команду `pip install -r requirements.txt`, start-команду `python bot.py`. В разделе Environment/Variables добавьте `BOT_TOKEN` и `ADMIN_ID` (при необходимости `DATABASE_PATH`). Для SQLite нужен persistent disk; без него база может сбрасываться после перезапуска. Условия бесплатных тарифов меняются — проверьте документацию выбранного сервиса.

## Где менять данные
- название, адрес, контакты, карту, рабочие часы, горизонт записи и интервал — `config.py`;
- исходные услуги, цены и шесть мастеров — `data/seed.py` (применяются к новой пустой базе);
- длительность отдельной услуги хранится в `services.duration_minutes`; начальное значение задаёт `DEFAULT_SERVICE_DURATION_MINUTES` в `config.py`;
- отзывы — `REVIEWS` в `data/seed.py`.

После изменения seed-данных удалите локальную демонстрационную БД или обновите строки SQL вручную. В рабочем проекте делайте миграции и резервные копии.

## Структура
`bot.py` запускает приложение; `config.py` содержит заменяемые настройки; `database/` — схема и запросы; `handlers/` — клиентские и административные сценарии; `keyboards/` — кнопки; `services/slots.py` — календарь; `states/` — FSM; `data/` — демонстрационные данные.
