# Демонстрационный Telegram-бот премиального барбершопа

Проект на Python и aiogram: клиент выбирает услугу, одного из шести мастеров, дату и свободное время, а администратор получает уведомление. **Все названия, цены, контакты, адрес и отзывы демонстрационные.**

## Возможности

- запись только на ближайшие 14 дней без прошедших дат и времени;
- часы: пн–пт 10:00–21:00, сб–вс 11:00–20:00; шаг записи 60 минут;
- независимое расписание мастеров и повторная атомарная проверка слота;
- «Моя запись»: ближайшая запись, услуга, цена, мастер, дата, время и отмена с подтверждением;
- уведомления администратору о создании и отмене;
- адрес, контакты, карта, отзывы и защищённая `/admin`-панель;
- SQLite с автоматическим созданием таблиц и заполнением услугами и шестью мастерами;
- `/help` и `/cancel`, проверка ввода, логирование и понятные сообщения об ошибках.

## Установка и запуск на Windows 11

### 1. Создайте Telegram-бота и получите токен

1. В Telegram откройте официальный аккаунт **@BotFather** и убедитесь, что username указан именно так.
2. Отправьте команду `/newbot`.
3. Введите отображаемое имя, затем уникальный username, заканчивающийся на `bot`.
4. BotFather пришлёт строку наподобие `123456789:AAExample...` — это `BOT_TOKEN`. Не публикуйте её.

### 2. Узнайте `ADMIN_ID`

Напишите боту **@userinfobot** (или другому боту для просмотра ID) и скопируйте свой **числовой** Telegram ID, например `123456789`. Используйте ID того аккаунта, который должен получать уведомления и открывать `/admin`.

### 3. Установите Python

1. Скачайте 64-битный Python 3.11 или 3.12 с [python.org](https://www.python.org/downloads/windows/).
2. В первом окне установщика обязательно отметьте **Add python.exe to PATH**, затем выберите **Install Now**.
3. Откройте новое окно **PowerShell** и проверьте установку:

```powershell
python --version
```

Если Windows открывает Microsoft Store или команда не найдена, попробуйте `py --version` и далее заменяйте `python` на `py`. Также можно отключить псевдонимы `python.exe` в «Параметры → Приложения → Дополнительные параметры приложений → Псевдонимы выполнения приложений».

### 4. Подготовьте проект

Распакуйте проект, например в `C:\Users\ВашеИмя\premium-barbershop-bot`. В Проводнике откройте эту папку, щёлкните по адресной строке, введите `powershell` и нажмите Enter. Затем выполните команды по одной:

```powershell
python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

После активации слева в строке PowerShell появится `(.venv)`. Временное изменение Execution Policy действует только в текущем окне.

### 5. Создайте и настройте `.env`

Находясь в папке проекта, выполните:

```powershell
Copy-Item .env.example .env
notepad .env
```

Замените примеры реальными значениями и сохраните файл:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_ID=ваш_числовой_Telegram_ID
DATABASE_PATH=barbershop.db
```

Не добавляйте кавычки и пробелы вокруг `=`. `ADMIN_ID` — только число. Файл `.env` исключён из Git. Не отправляйте его другим людям и не показывайте токен на скриншотах. При утечке токена выполните `/revoke` у BotFather и укажите новый токен.

### 6. База данных

Создавать базу вручную **не нужно**. При первом запуске бот сам создаст рядом с `bot.py` файл `barbershop.db`, все таблицы, услуги и шесть мастеров. У аккаунта Windows должны быть права на запись в папку проекта. Чтобы начать с чистой демонстрационной базы, остановите бота и удалите `barbershop.db`; при следующем запуске он будет создан заново.

### 7. Запустите бота

В активированном виртуальном окружении выполните:

```powershell
python bot.py
```

Оставьте окно PowerShell открытым. В Telegram откройте созданного бота, нажмите **Start** или отправьте `/start`. Для остановки нажмите **Ctrl+C**. При следующем запуске откройте PowerShell в папке проекта и выполните:

```powershell
.\.venv\Scripts\Activate.ps1
python bot.py
```

Одновременно должна работать только одна локальная копия бота с этим токеном. Компьютер должен быть включён и подключён к интернету.

## Как проверить работу

1. Нажмите «Записаться», выберите услугу, мастера, дату и время.
2. Введите имя и телефон, затем подтвердите. Аккаунт с `ADMIN_ID` должен получить данные записи.
3. Начните новую запись к тому же мастеру: занятый слот не должен отображаться. У другого мастера это время останется доступным.
4. В «Моя запись» выберите отмену и подтвердите её: слот освободится, администратор получит сообщение.
5. С аккаунта администратора отправьте `/admin`. С другого аккаунта доступ должен быть запрещён.

Для программной самопроверки из активированного окружения можно выполнить:

```powershell
python -m pytest -q
```

## Решение частых проблем

- **`BOT_TOKEN и ADMIN_ID не заданы`** — файл должен называться именно `.env`, находиться рядом с `bot.py` и содержать оба значения.
- **`ADMIN_ID должен быть целым числом`** — удалите `@`, пробелы и прочие символы, оставив числовой ID.
- **`Token is invalid`** — заново скопируйте токен из BotFather без пробелов и кавычек.
- **Бот не отвечает** — проверьте интернет, отсутствие второй запущенной копии и сообщения об ошибках в PowerShell.
- **`No module named ...`** — активируйте `.venv` и повторите `python -m pip install -r requirements.txt`.

## Где менять демонстрационные данные

- название, адрес, контакты, карту, рабочие часы, горизонт и интервал записи — `config.py`;
- исходные услуги, цены и шесть мастеров — `data/seed.py` (применяются к новой пустой базе);
- длительность услуги хранится в `services.duration_minutes`, начальное значение задаёт `DEFAULT_SERVICE_DURATION_MINUTES`;
- отзывы — `REVIEWS` в `data/seed.py`.

После изменения seed-данных удалите локальную демонстрационную БД или измените соответствующие записи в SQLite. В реальном проекте перед изменениями делайте резервную копию.

## Структура

`bot.py` запускает приложение; `config.py` содержит настройки; `database/` — схему и запросы; `handlers/` — клиентские и административные сценарии; `keyboards/` — кнопки; `services/slots.py` — календарь; `states/` — FSM; `data/` — демонстрационные данные.
